There must be a better way

Automate those manual jobs

This client had a manual process to reconcile their orders once a quarter between two different systems. This involved running an export from one on-line system and then manually entering the orders into Microsoft RMS.
   
We worked with them to build an end to end system. It was scheduled to run nightly and import the days orders from the online order system, convert into the format required by the RMS and then record the entries.
   
This system is designed to run seamlessly without any user intervention - saving not only time but removing a manual process that no one liked doing.
   
Technologies: .NET, MVC, API Integration, SQL
